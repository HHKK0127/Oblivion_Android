## 1. 数字の是正（v618 の 264 は誤集計）[確定(命令)（negative）]

v618 で報告した dist 分布の合計は **264** で、総数 322 と合っていなかった。原因は 2 つ:

| 欠落 | 件数 | 理由 |
|---|---|---|
| dist=0 の非 setter（GF22＋other5） | **27** | 私が dist=0 を「setter の 116」に縮めて表示した |
| dist≥8（窓を 8 命令にしていた） | **31** | u60_1 の窓が 8 命令で、dist 8/9/11 を落とした |

→ **27 + 31 = 58** が欠落。**窓を 20 命令に広げ、全 callee を計上した完全表**を作成:

### `push 0xFAE`（全 322 が push 形。mov/cmp 形は 0）の dist × callee

| dist | UF | US | GF | other | 計 |
|---|---|---|---|---|---|
| 0 | 88 | 28 | 22 | 5 | **143** |
| 1 | 28 | 5 | 99 | 0 | **132** |
| 2 | 3 | 2 | 4 | 1 | **10** |
| 4 | 1 | 0 | 0 | 4 | **5** |
| 6 | 1 | 0 | 0 | 0 | **1** |
| 8 | 0 | 0 | 0 | 24 | **24** |
| 9 | 0 | 0 | 0 | 5 | **5** |
| 11 | 0 | 0 | 0 | 2 | **2** |
| **計** | 121 | 35 | 125 | 41 | **322** ✓ |

- 窓 20 命令で **call が無い push は 0 件**。→ **322 = 完全一致**。

## 2. 真の引数窓で書き手を再計数 = **155** [確定(命令)]

- **trait が arg1(`[esp+4]`) に残る条件**＝`push 0xFAE` の後、call までに **`push` / `sub esp` が無い**こと（`mov reg,<tile>`＝this 設定は引数ではない）。
- この条件での計数:

| 区分 | 件数 |
|---|---|
| **書き手（setter & trait 保持）** | **155**（UF 120 / US 35） |
| 読み手（getter & trait 保持） | 125 |
| 失格（間に push/sub esp） | 37 |
| その他 callee | 41 |

- 書き手の dist 分布: **0=116 / 1=33 / 2=5 / 4=1 → 155**。
- → **査読の「116 は下限、dist=1 の 33 も書き手」は正しい**。v618 の 116 を **155 に訂正**（v617 の 116 も同様）。
- **V-618-2 は「切り分け」ではなく「this 設定の除外」で決着**（上記条件）。

## 4. 汎用フラグ仮説を支持 [部分確定]

- **`menuRoot.user0 == 2.0` は chargen 専用ではなく「UI/メニューがアクティブ」の汎用フラグ**。
  - 読み手: `fcomp [0xA379B4]` 121 箇所（うち 64 が `push 0xFAE` 近傍）。判定先は `0x582160 InterfaceManager_GetSingleton`・`0x589B70 GetTileMenu`・`0x578F60 IsMenuMode` 等。
  - 書き手: **29 箇所**（上記）が多数のメニューに分散。
  - user0 の書き手は全部で **155**（うち 2.0 を書くのは 29）。
- 汎用経路: **`0x585190 Menu::EnableMenu` の callers = 46**（`0x593AB8`/`0x595714`/`0x5963FA`/… 多数のメニュー処理）。
- → **v617 の「menuRoot.user0==2.0 が chargen 構築のゲート」は、より正確には「汎用の UI アクティブフラグをゲートに使っている」**。chargen 固有の入口は **builder `0x5CA010` の `0x40C` 直値**の側。
