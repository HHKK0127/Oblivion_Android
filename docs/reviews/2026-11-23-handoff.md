## §6. 構造的な論点（評価の核心）

1. **成果の滞留**: レーンB の 10 ブランチ・21 コミットが未マージ。master の chargen はレーンA の `Panel`（実験的）、ローディングは矩形バーのまま `[データ]`。
2. **同一機能の二重実装**: chargen を「手書き21ページ」（レーンB・未マージ）と「widget 化＋descriptor」（レーンA・master）で別々に作った。**レーンA が採用された**が、レーンB の作業は捨てる前提が明示されていない。
3. **メニューが手書きで、既存の XML インタプリタが本番未使用**: `MenuXmlInterpreter`/`MenuUiBuilder`/`MenuUiInstantiator` の参照元は master でも **tests と自身のみ**（`[データ]` grep）。RE は「UI はデータ（104 XML）、C++ は user trait を埋めるだけ」を確定（`v612` §9・`v634`）`[文書]`。両レーンとも実行時解釈はしていない。
