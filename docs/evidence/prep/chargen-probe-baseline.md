## 出典（知り方）

- **測定値**: 本セッション（#183 の準備時）の実測。**タップ座標・スクロール位置・
  日付の完全な記録は残っていない**（`未確認`）。以下は同じ値が出るはずの条件を
  レイアウトから復元したもの。
- **タップ座標の復元**（`race_sex_panel.cpp` の定数から検算、暗算していない）:
  - `CANVAS = 1280x960`, `PANEL_CANVAS = (100, 195)`, `ROW_HEIGHT = 93`,
    `WINDOW_WIDTH = 500`, `SCROLL_VISIBLE = 6`（`race_sex_panel.h:293-317`）
  - アプリのサーフェスは **1280x870**（smoke ログ `Menu hit layout (screen 1280x870)`）。
    `s = min(1280/1280, 870/960) = 0.90625`、`panelOrigin = (150.625, 176.719)`
  - Main は 6 item（`6 > 6` は偽）なのでガター無し = `pane_w = 500` → device 幅 453.1
  - Main 行の device 中心:

    | 行 | id | ラベル | 中心 (x, y) |

    | 1 | 202 | Face | (377, 303) |

- **スクロール位置**: Main は 6 item で `SCROLL_VISIBLE` と同数 → スクロールバー無し、
  `scroll_rows_ = 0`（`race_sex_panel.cpp:170`）。

## 測定条件（固定）

- 画面: `wm size 1280x960` / `wm density 240` / `rotation 1`（既定の smoke 条件）
- アプリのサーフェス: 1280x870（上記）
- UI: chargen パネル（`ChargenUi::Panel`・console `chargenpanel` の既定）。**Legacy UI
  ではない**
- ページ: Main（`PAGE_MAIN`）、スクロール 0
- 端末: emulator-5554
- 日付: 本記録の作成は 2026-11-27。**元の実測日は `未確認`**

## 合格条件（値そのものを賭けない）

`scripts/chargen_probe.py` は次を満たせば合格:

- **`Eyes == 0`**（構造的: 反転が無いことの確認）
- **`Race > 1000`**（「変化している」ことの確認。ページ遷移は数千画素が動く）

**85958 は参考値**。一致しなくても失敗にしない。理由: 絶対値はレイアウト依存で、
#182 など正当な UI 変更で動く。動いたときに計測器が壊れたように見えると、以後の
「Eyes が反転した」という測定も信用できなくなる。
