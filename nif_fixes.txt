### Bug #1: ServiceLocator::has() Always Returns False
**File**: `engine/imperial_weave.cpp`  
**Function**: `ServiceLocator::has()`  
**Severity**: P0 - Critical

**Problem**: The method is stubbed to always return `false`, making service existence checks completely non-functional.

```cpp
// BUGGY CODE:
bool ServiceLocator::has(const std::string& typeName) const {
    (void)typeName;
    return false;  // Implementation incomplete
}
```

**Fix**:
```cpp
bool ServiceLocator::has(const std::string& typeName) const {
    std::lock_guard<std::mutex> lock(mutex_);
    for (const auto& pair : services_) {
        if (pair.second.name == typeName) return true;
    }
    return false;
}
```

### Bug #8: DOT Not Implemented in applyBleed()
**File**: `game/combat_manager.cpp`  
**Function**: `CombatManager::applyBleed()`  
**Severity**: P1 - High

**Problem**: Bleed applies immediate damage only, not damage over time.

```cpp
// BUGGY CODE:
float totalBleedDamage = duration * damagePerSec;
target->takeDamage(totalBleedDamage * 0.1f);  // Only 10% immediate damage
```

**Fix**:
```cpp
// combat_manager.h
struct ActiveBleed {
    float remainingTime;
    float damagePerSec;
    uint32_t targetNpcId;
};
std::unordered_map<uint32_t, ActiveBleed> activeBleeds;

// combat_manager.cpp
void CombatManager::applyBleed(std::shared_ptr<NPC> target, float duration, 
                               float damagePerSec, uint32_t sourceId) {
    if (!target) return;
    
    ActiveBleed bleed{duration, damagePerSec, target->npcId};
    activeBleeds[target->npcId] = bleed;
    target->takeDamage(damagePerSec * 0.5f);  // Initial damage
}

void CombatManager::updateBleeds(float deltaTime) {
    for (auto it = activeBleeds.begin(); it != activeBleeds.end(); ) {
        auto& bleed = it->second;
        bleed.remainingTime -= deltaTime;
        
        auto target = npcManager->getNPC(bleed.targetNpcId);
        if (target && target->status.isAlive()) {
            target->takeDamage(bleed.damagePerSec * deltaTime);
        }
        
        if (bleed.remainingTime <= 0.0f) {
            it = activeBleeds.erase(it);
        } else {
            ++it;
        }
    }
}
```

### Bug #33: JSON Escape Missing in Serialization
**File**: `save_system/save_manager.cpp`  
**Function**: `SaveManager::serializeGameState()`  
**Severity**: P1 - High

**Problem**: Special characters in strings not escaped, producing invalid JSON.

**Fix**:
```cpp
std::string escapeJsonString(const std::string& input) {
    std::string output;
    for (char c : input) {
        switch (c) {
            case '"': output += "\\\""; break;
            case '\\': output += "\\\\"; break;
            case '\b': output += "\\b"; break;
            case '\n': output += "\\n"; break;
            case '\r': output += "\\r"; break;
            case '\t': output += "\\t"; break;
            default:
                if (c < 0x20) {
                    char buf[8];
                    snprintf(buf, sizeof(buf), "\\u%04x", c);
                    output += buf;
                } else {
                    output += c;
                }
        }
    }
    return output;
}
```
